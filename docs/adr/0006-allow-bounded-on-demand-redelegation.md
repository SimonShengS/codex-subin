# Allow bounded on-demand re-delegation

Codex Subin allows Root and first-generation subagents to delegate independently bounded work when this materially improves parallelism, context isolation, or independent evidence. Re-delegation does not require a separate Root authorization step: the spawning subagent remains within its inherited objective and write scope, marks every nested child as a non-redelegating leaf, consolidates child evidence, and prevents overlapping writers. The maximum logical hierarchy is Root → subagent → leaf, but current public Codex configuration does not expose a supported numeric `agents.max_depth` key, so this depth is instruction-governed and runtime-probed rather than mechanically enforced. Subin's optional Session Defaults use `agents.max_concurrent_threads_per_session = 10` as a high-capacity ceiling excluding Root; it is not a required fan-out or a change to the seven-role catalog.
